能转能拆的解剖图

把机器与抽象系统画成可交互等轴测图
入口命令
/anatomy
在 Claude Code 里一句话描述对象
输出形态
SVG 交互 · WebGL 可选 · 3D 实验
01装INSTALL
$npx skills add wheresryan22/anatomy
一行命令装进本地 skills
02指令PROMPT
›/anatomy explain …, interactive
在 Claude Code 里调用，把 “…” 换成你想看懂的机器或系统；加 interactive 要可操作版本
03产出OUTPUT
  • 交互 SVG默认
  • WebGL 特效可选
  • 3D 视图实验性
FIG.01 · 等轴测拆解示意EXPLODED
可拆：部件沿轴分离，看清层级 · 可转：拖动换视角
示意图为本卡绘制，非工具实际输出

能画什么CAPABILITIES

不是一张静态插图，而是一台可以拆开、转动、动手摸的模型。
01

SVG 交互核心

精修等轴测线框，部件可拆可转；浏览器直接打开就能操作。

拆解视图旋转视角部件分层
02

WebGL 特效可选

火 / 水 / 等离子体等 shader 特效，让流动、燃烧这类过程动起来。

03

抽象系统不只物理机器

连接池、CDN 缓存这类看不见的系统，也能画成「能操作的机器」。

连接池CDN 缓存…你的系统
04

3D 视图实验性

还在实验阶段，能用，但别当成稳定功能来依赖。

一行安装 · INSTALL
$npx skills add wheresryan22/anatomy
装好后在 Claude Code 输入 /anatomy explain …, interactive
