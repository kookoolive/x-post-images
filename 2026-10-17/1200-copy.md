## post
「技术护城河基本结束了。」前 X 产品负责人 Nikita Bier 这句话 2.5 万赞、1.3 万收藏。他说还剩三条：专有数据、网络效应、物理实体。

levelsio 跟帖补成六条——专有数据/内容、网络效应/社区、受众/分发、物理实体、资本、牌照监管——然后真去逐条改自己的产品：Nomads 城市数据做成付费 API（年费 $2,490–$9,990）；社区门槛从 $99 降到 $1 换网络效应；邮件 + Telegram 订阅 18.7 万人；30 天里排了 8 场线下聚会，还在做一台 90 年代复古 PC 硬件。监管这一条他直说：不擅长，不碰。

他还顺手吐槽：最新一批 YC 全是「Cursor for 某行业」的 harness 加硬件。

我的判断：harness 不是护城河，它是生产护城河的机器。对做 Agent 产品的人，六条也不是平均分布的。资本和牌照多数人够不着；真正能每天积累的只有两条——用户用你时才产生的数据，和你随时叫得到的那群人。

一个自测（评论区 @ecombeckett 的题）：如果 AI 明天用代码复刻一个更便宜的你，用户还有理由选你吗？答不上来，就是还没护城河。

做 Agent 产品，本周可以先做 5 件事：

1. 单独记下「用户用完才有」的数据：纠错、偏好、被拒的方案。这是别人抄不走的部分。
2. 每周看一次：这些记录有没有让 Agent 下次做得更好。没有回流的数据只是日志。
3. 建一个能直接触达的渠道：邮件列表或群，不靠平台推荐。
4. 加一个真实世界触点：一场聚会，或一个交付到手的结果。
5. 拿复刻测试过一遍自己的产品，写下唯一的答案。

模型每个季度都在变便宜。能被一次 prompt 复刻的东西，都不算你的。
