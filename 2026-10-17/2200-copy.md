## post
DeepSeek 今天发了 V4.1-Flash-1017，1.5 万赞、127 万次浏览。最值得看的不是榜单，是这句：新模型「训练时专门为 DeepSeek Harness 做了优化」，想要完整效果，得升级到 Harness 0.2.1-rc.1 以上。

Claude Code 配 Anthropic，Codex 配 OpenAI，现在 DeepSeek 也有了自己的那套 loop。模型和跑它的 harness，开始被当成一个产品一起训。

官方自报的数：DeepSWE v1.1 拿 77.0，Claude Opus 5 是 74.0，GPT-5.6-Sol 73.0；官方散点图上，它每个任务约 0.2 美元，Opus 5 约 12 美元。

但注意脚注：Terminal-Bench 4.0 是放在 Claude Code 里跑的，它 42.3，Opus 5 是 51.8；DeepSWE 用的是 mini-SWE 框架。两个榜、两套 loop，结论正好相反。

还有个小坑：@AM09_21 提醒，npx 现在装到的 Harness 还是 0.2.0-rc.2，跑不出新模型的效果，要从官方仓库自己构建。

我的判断：「哪个模型最强」会越来越没意义。该问的是：这个模型放进我的 harness、跑我的任务，做得怎样，每个任务花多少钱。上午说 harness 不是护城河；但对模型厂来说，harness 正在变成模型的一部分。

做 Agent 产品，本周可以先做 5 件事：

1. 攒 20 个自己的真实任务。换模型前，先在自己的 harness 里重跑一遍，不看榜单直接切。
2. 评测记录里同时写模型版本和 harness 版本。0.2.0 和 0.2.1 可能就是两个结果。
3. 按「每个任务花多少钱」算账，不按每百万 token 单价。输出更短的模型，单价不变也更便宜。
4. 用厂商自带的 harness 跑一遍做对照，看你自己的封装吃掉了多少能力。
5. 免费期写进日历：DeepSeek 的 Search / Fetch 在自家 Harness、Claude Code、Codex 里的服务端调用暂时免费，北京时间 11 月 1 日 0 点起每千次 0.75 美元。

模型在变便宜，「模型 + loop」这对组合却越来越难拆。选模型，连它的 harness 一起选。
