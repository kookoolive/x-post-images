## post
OpenCode 昨晚公开：一次「大规模蒸馏攻击」打穿了正在下线的旧系统，约 1.4% 的 Console 用户被波及——前提是你在工作区里存过 OpenAI、Anthropic 或 Google 的 API Key。官方说没收到邮件的不受影响；收到的人，有人已经报了一夜 $400+ 的异常账单。三家模型厂都在一起清。

别被「蒸馏」三个字带偏。攻击者要的不是你的 prompt，是你钥匙背后那台能无限刷模型的计费账户。API Key 本质上就是带 HTTP 头的现金。

我的判断：方便把 Key 存进第三方 Console，等于把信用卡留在别人店里。Harness 越强，钥匙柜越大；柜越大，一次侧门的爆炸半径越大。10-14 我们说过 MCP 过期会走侧门；这次是侧门已经打开，钥匙被直接拿走。

本周 5 件事（今天就能做完）：

1. 盘点：哪些工具 / Console / IDE 插件里还躺着你的 Provider Key。列出清单。
2. 没收到 OpenCode 邮件也无所谓——凡是「为了方便」存过 Key 的地方，先轮换一次。
3. 每把 Key 开花费上限 + 告警；没有上限的 Provider，就不要长期挂着。
4. 本机只留环境变量，不往聊天、Agent 会话、截图里贴 Key。会话记录当 ~/.ssh 看。
5. 第三方工具优先 OAuth / 短时令牌；非要存 Key，就用只能打白名单模型、预算极低的专用 Key。

模型在变便宜，Key 泄漏的代价没有。Agent 时代，钥匙管理不是运维细节，是产品能力。
