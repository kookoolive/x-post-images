攻击者要的不是 prompt

要的是钥匙背后那台能无限刷模型的计费账户。没收到邮件的不受影响；收到的人，先轮换 Key，再查账单。

本周 5 件事 · 今天就能做
  1. 盘点工具 / Console / 插件里还躺着哪些 Provider Key
  2. 凡「为方便」存过的地方，先轮换一次
  3. 每把 Key 开花费上限 + 告警
  4. 本机只留环境变量；会话记录当 ~/.ssh
  5. 第三方优先 OAuth / 短时令牌；非要存就用低预算专用 Key
模型在变便宜，Key 泄漏的代价没有。钥匙管理不是运维细节，是产品能力。
