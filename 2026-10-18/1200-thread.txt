OpenCode 昨晚公开：一次「大规模蒸馏攻击」打穿正在下线的旧系统，约 1.4% Console 用户被波及——前提是你存过 OpenAI / Anthropic / Google 的 API Key。

没收到邮件的不受影响；收到的人，有人已经报了一夜 $400+ 的异常账单。
---
别被「蒸馏」带偏。攻击者要的不是你的 prompt，是钥匙背后那台能无限刷模型的计费账户。

API Key 本质上就是带 HTTP 头的现金。
---
我的判断：方便把 Key 存进第三方 Console，等于把信用卡留在别人店里。

Harness 越强，钥匙柜越大；柜越大，一次侧门的爆炸半径越大。
---
10-14 我们说过 MCP 过期会走侧门；这次是侧门已经打开，钥匙被直接拿走。
---
本周 5 件事（今天就能做）：
· 盘点哪些工具里还躺着 Provider Key
· 凡「为方便」存过的地方，先轮换一次
· 每把 Key 开花费上限 + 告警
· 本机只留环境变量，会话记录当 ~/.ssh
· 第三方优先 OAuth / 短时令牌；非要存就用低预算专用 Key
---
模型在变便宜，Key 泄漏的代价没有。Agent 时代，钥匙管理不是运维细节，是产品能力。
