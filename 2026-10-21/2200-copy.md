## post
Anthropic 和投资研究公司 Citrini 做了一场实验：把内部研究模型塞进 Claude Science，让它设计能绑住蝎毒神经毒素的蛋白 minibinder。

64 小时，主要自主跑；人类只给了 1 条初始 prompt + 4 次 follow-ups。模型生成了 318,484 个设计，自己挑出 180 个；团队又加了 31 个，共 211 个送去 Adaptyv Bio 和 Twist Bioscience 做结合实验。

结果：17 个达到 binder 标准，覆盖 5 种毒素里的 4 种；巴西毒 Ts1 一个都没中；没有任何一分子同时绑住多种毒素。最强的 Cn2-B1 / Cn2-B2 对墨西哥毒 Cn2 达到个位数 nM，还能跟已知中和抗体 LR 抢同一位点。

Anthropic 自己写得很清楚：**没有做细胞/动物中和实验，不宣称已做出抗蝎毒血清。** 蝎蜇一年约 120 万例、死 3250+（多为儿童）；现有抗毒仍是挤毒→打马→抽抗体。专家评语的 gist：结合不再是主瓶颈，真正难点在变成可及药物。

我的判断：结合 ≠ 解药。Agent 把设计漏斗从几个月压到几天，但验证、中和、可及性才是产品。非生物专家能靠 Agent 把设计做到「可送实验室」——这一步值钱；把「出了 17 个 binder」写成「AI 做出了抗毒血清」——这一步骗人。

本周 5 件事：
1. 读 Anthropic 原文，把「binder」和「antivenom」拆开讲，别跟风标题党
2. 自己的 Agent 实验也写清：做到哪一步、没做哪一步、谁做了实验验证
3. 漏斗数字要报全：生成量 / 送测量 / 命中量 / 未做验证 = 0
4. 多靶点设计失败也写进结论（本次无一 multitoxin 命中），别只晒成功子集
5. 把「可及性」写进成功标准：安全、稳定、负担得起、送到蜇伤高发区

Agent 压缩的是搜索空间，不是临床与供应链。
