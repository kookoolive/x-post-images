真正的产品不是「让 Agent 进店」，是给 Agent 独立身份 + 限额 + 默认审批 + 可撤销。

Walmart 昨天公开了 Agent Profiles 和 Agent Gateway。下月起，每个 AI Agent 在顾客账号里会有独立档案：代理买的东西单独可见；每笔默认要你批，或者设花费上限（比如 $50 / $100 / $200）；随时能撤销。官方自己的比方：像给信用卡加一个持卡人，再写上额度。

同一天对照很刺眼：Amazon 还在堵 Agent 进站，Walmart 发通行证。通行证上写了边界：默认审批；额度内仍可加一道确认；Agent 拿不到支付卡信息、不能改支付方式；价格与人站一致；违约就封禁；代理乱买，退货规则照常适用。

Agent Gateway 是给公司与开发者的 MCP beta：比浏览器爬页面快，也能帮找「常买」而不必把完整购买史塞给模型。

我的判断：Agent 没有独立身份时，出事分不清是人还是模型。购物如此，邮箱、代码仓、账单同理。先发身份，再谈放权。

本周 5 件事：
1. 给每个能动钱、动写权限的 Agent 建独立身份，日志分开
2. 默认每笔审批；额度只做例外通道
3. 支付凭证与 Agent 运行时隔离，改支付方式必须人批
4. 对接电商、SaaS 优先正式 API 或 MCP，别再靠浏览器刮
5. 写清违约与撤销，能一键关 profile

没有独立身份的 Agent，只是借你的账号在瞎逛。
