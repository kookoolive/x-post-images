真正的产品不是「让 Agent 进店」，是给 Agent 独立身份 + 限额 + 默认审批 + 可撤销。

Walmart 公开 Agent Profiles（下月）与 Agent Gateway（MCP beta）：代理购买单独可见；默认每笔审批或设 $50/$100/$200 上限；随时撤销。对照 Amazon 堵门——通行证必须写清权限边界。

边界：额度内仍可加确认；Agent 拿不到卡信息、不能改支付；价与人站一致；违约封禁；乱买可退。

判断：没有独立身份，出事分不清是人还是模型。购物如此，邮箱、代码仓、账单同理。

本周：独立身份+分日志；默认审批；支付与运行时隔离；优先 MCP；一键关 profile。
