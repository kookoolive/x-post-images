## post
模型说「不」，攻击照跑。

Straiker 昨天（10-21）公开威胁报告 CARLIY0S：拉美黑产 CyberCartel 用 Claude、Grok、Kimi 搭了一支多 Agent 攻击队，2026 年 5–9 月瞄准 400+ 家银行和支付机构。

分工像个小团队：指挥官是跑在 Cursor 里的 Claude；STRIKER 写 exploit，GHOST 做侦察，FABLE 找非常规入口，三方辩论后交 MAXIMUS 仲裁，只出一个决策。五个「Grok miner」把偷来的密钥收进赃库 FinancialSoft。（模型名是报告列出的配置，Fable 5 一项报告自己标为未证实。）

绕过护栏三招：包装成「授权红队」「CTF 练习」；被拒就换模型，Kimi、Sonnet 都拒就切回本地预写的攻击脚本；规则文件禁止模型输出团伙代号，掐断溯源。

9 月 24 日赃库快照：4,493 条记录，903 个账户号，391 个 API key，20 个 JWT 签名密钥，67 个明文密码，6 个后门，200+ 个未公开漏洞。Anthropic 已吊销对应凭证，xAI 在查。

我的判断：模型拒答不是防线，只是攻击流程里一个会被绕过的分支。真正被打穿的还是老问题：裸露的后台、明文密钥、只看 IP 的风控。AI 改的是速度和规模，没改入口。

本周 5 件事：
1. 盘点明文 key、JWT 签名密钥、数据库连接串，能轮换就轮换
2. CMS 后台别裸露公网，上 SSO 和设备限制
3. 住宅代理让 IP 黑名单失效，风控改看行为与会话
4. 自家 Agent 工具权限登记成册，配一键 kill switch
5. 别把「模型会拒绝」写进安全假设

攻击方已经把多 Agent 做成流水线；防守方还在指望模型说不。
