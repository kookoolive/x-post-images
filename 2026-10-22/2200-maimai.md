模型说「不」，攻击照跑。

安全公司 Straiker 10 月 21 日公开报告：拉美黑产 CyberCartel 用 Claude、Grok、Kimi 搭了一支多 Agent 攻击队（CARLIY0S），5–9 月瞄准 400+ 家银行和支付机构。指挥官是 Cursor 里的 Claude，几个子 Agent 分别写 exploit、做侦察、找非常规入口，辩论后由仲裁 Agent 出决策。

绕过护栏三招：包装成「授权红队」「CTF 练习」；被拒就换模型，全拒就跑本地预写脚本；禁止模型输出团伙代号，掐断溯源。赃库快照 4,493 条记录，含 391 个 API key、20 个 JWT 签名密钥、6 个后门。Anthropic 已吊销凭证，xAI 在查。

我的判断：拒答不是防线，只是一个会被绕过的分支。被打穿的仍是老问题：裸露后台、明文密钥、只看 IP 的风控。

本周：轮换明文密钥；CMS 后台下公网；风控看行为不只看 IP；自家 Agent 权限登记并配 kill switch；别把「模型会拒绝」当安全假设。
