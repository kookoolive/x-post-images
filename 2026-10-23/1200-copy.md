## post
真正该捐的不是一个品牌名，是「一份文件夹就能跨平台教 Agent」这件事本身。

Anthropic 昨天把 Agent Skills 开源标准捐给了 Agentic AI Foundation（AAIF）——去年他们把 MCP 也捐给了同一家基金会。一起移交的还有名字、logo、GitHub org 和 agentskills.io。自 2025 年 12 月公开标准以来，已有 70+ 平台接入（含 ChatGPT、Cursor、GitHub Copilot、VS Code）；社区侧约 100 万个 skill 发布、近 2.8 亿次安装。许可不变，不加入 AAIF 也能继续用、继续贡献。

同一天 AAIF 还收了另外三件：OpenAI 的 Open Responses、Hugging Face 的 OpenEnv、阿里的 OpenSandbox。Agent 栈四层——会什么、怎么连模型、怎么训/评、在哪安全跑——开始往同一张中立桌上堆。

我的判断：Skill 不是提示词收藏夹，是可移植的程序性知识。捐出去之后，竞争会从「谁家的格式」转向「谁家的 skill 真能验、敢不敢装」。路线图里已经点名：版本化发布、正式提案流程、写 skill / 装 skill 的安全指引——这三样不落地，中立治理只是换了个托管方。

本周 5 件事：
1. 盘点团队在用的 skill：哪些只在一个产品里能跑，哪些已经是标准文件夹
2. 新 skill 默认按 agentskills.io 规格写（SKILL.md + 脚本/参考），别再写死某一家的私有字段
3. 装第三方 skill 前先审它要读哪些文件、调哪些工具；权限清单比风险分更管用
4. 给关键 skill 加最小验收：同一任务对照跑，留下「更好」的证据，不只是「能跑」
5. 关注 AAIF 的版本化与安全指引草案，把自己踩过的坑写进提案，而不是私下打补丁

格式一中立，护城河就回到内容：你的流程、你的验收、你敢不敢让别人复用。
