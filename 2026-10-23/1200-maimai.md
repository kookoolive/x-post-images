真正该捐的不是品牌名，是「一份文件夹就能跨平台教 Agent」。

Anthropic 把 Agent Skills 开源标准捐给了 Agentic AI Foundation（AAIF）——去年 MCP 也捐给了同一家。移交含名字、logo、GitHub org、agentskills.io。自 2025-12 公开以来：70+ 平台接入（含 ChatGPT、Cursor、GitHub Copilot、VS Code）；约 100 万 skill、近 2.8 亿次安装。许可不变，不入会也能用。

同日 AAIF 另收三件：OpenAI Open Responses、Hugging Face OpenEnv、阿里 OpenSandbox。会什么 / 怎么连模型 / 怎么训评 / 在哪安全跑——四层往同一张中立桌堆。

我的判断：Skill 不是提示词收藏夹，是可移植的程序性知识。捐出去后，竞争从「谁家格式」转向「谁家 skill 真能验、敢不敢装」。路线图已点名版本化、正式提案、写/装 skill 的安全指引——这三样不落地，中立治理只是换了托管方。

本周 5 件事：
1. 盘点：哪些 skill 只绑一家产品
2. 新 skill 默认按 agentskills.io 规格写
3. 装前审文件/工具权限，别只看风险分
4. 关键 skill 加最小验收对照
5. 把踩坑写进 AAIF 提案，别私下打补丁

格式一中立，护城河就回到内容：你的流程、你的验收、你敢不敢让别人复用。
