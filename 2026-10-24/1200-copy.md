## post
别再等下一颗更大的模型；先修 harness / 交互面。

Simular 开源了 Agent S4（约 10/20）：不改模型权重，只进化 computer-use Agent 用的 Python「shadow interfaces」——小工具库 + 何时该用哪把刀的知识。meta-agent 从合成任务轨迹里改接口仓库，再用验证集做种群筛选；任务模型与 harness 全程固定。

OSWorld V2（108 题，严格 binary）：Qwen3.8-27B + 进化接口 ≈ 21.3%；同模型 + 固定工具 ≈ 5.56%（约 3.8×）。同一套严格计分下，高于 GPT-5.5（13.0%）和 Claude Opus 4.8（20.6%）。推理成本约 $1.10/task，相对前沿约 $25–72——但进化算力常未计入，别只看单价。

点醒我的不是分数：Agent 经常卡在过时交互设计——表格单元格点一遍，而一行代码就能写完；把两千行文件全打进 shell 只为找一个函数。接口与「何时用哪把」若全靠人手维护，跟不上新应用、新工作流、新模型。

我的判断：小开源模型 + 会进化的工具层，可以打过贵闭源。下一波差距，更多来自交互面与 harness，而不是再堆参数。

本周 5 件事：
1. 盘点 Agent 工具层：哪些还在「人手点一遍」的形状
2. 给高频桌面任务写可编程接口，别只堆 GUI 点击
3. 同一模型固定工具 vs 可改接口，跑最小对照验收
4. 进化/合成任务要留验证集，防过拟合训练集
5. 算成本时把进化算力单列，别只比推理单价

先改接口，再换模型。
