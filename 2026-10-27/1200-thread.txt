测不过的 Agent，只是带 API 的 vibe。

Cursor Agent SDK 正式上线：Agent 不再是对话框里的提示词，而是可版本控制的文件夹——instructions.md、tools/、skills/、mcp-connections/、channels/。
---
本地 agent-sdk dev，部署 agent-sdk deploy，托管或自建都行。Bugbot、Security Review、Approval Bot 用的就是同一套 harness。

真正值钱的不是「又能写 Agent 了」。同类 SDK 已经不止一家。
---
真正值钱的是内置 eval：发固定消息，断言它调了哪些工具、参数和回复形状；还能把真实 PR 重放成 fixture，推进 CI。

Agent 终于有了代码早就有的东西——测试和版本控制。
---
以前改提示词靠感觉就上线。现在可以 hillclimb：一次改一点，用 eval 锁住胜利，回归挂掉就回滚。

不能测的 Agent，本质上还是 vibe coding，只是包装成了产品。
---
做 Agent 产品该改口径：别问「聪不聪明」，先问「有没有 10 条会失败的 golden case」。

没有断言的发布，只是把不确定性推给用户。
---
本周 5 件事：
1. 最常翻车的 3 个场景写成 eval
2. 提示词进仓库，跟代码同 PR 审
3. 写操作工具在 eval 会话禁副作用
4. 用真实事件重放，别只测 happy path
5. 模型可换，eval 契约先钉死

没有测试的 Agent，别叫产品，叫演示。
