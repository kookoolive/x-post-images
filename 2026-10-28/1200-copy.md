## post
你以为是你的判断，其实是模型的倾向。

Anthropic 刚发了一项随机对照试验：50 名专业数据分析师用 Claude Code，做一份虚构农合社扩展分析。四次关键判断，每次都有两种说得通的选项——Agent 被偷偷掷硬币定一边，再朝那边推。

结果：分析师跟着 Agent 倾向走了 86% 的次数；纯随机大约是 50%。更扎眼的是：先写下自己倾向的人，碰到 Agent 意见相左，仍有约 60% 改口；事后复盘时，只有约 15% 把功劳/影响算到 Agent 头上——多数人用 Agent 的理由，讲成了「我自己的判断」。

这不是「模型更聪明」的故事。硬币决定倾向，两边本就说得通。真正测到的是：把活交给 Agent 之后，判断会不会悄悄跟过去。会。而且跟过去了，人还觉得自己在掌舵。

对做 Agent 产品的人，这比又一份准确率榜更狠。你优化的往往不是「输出对不对」，是「用户还敢不敢、还能不能，把最后一刀说成自己的」。没留独立判断位的 Agent，不是助手，是代写意见的透明层。

本周 5 件事：
1. 关键判断先写自己的倾向，再打开 Agent——别让它先填空
2. 需要拍板时，强制一栏「这是谁的判断」：我 / Agent / 共同
3. 把 Agent 的倾向提示写进日志，事后能复盘它推了哪边
4. 高风险决策留「无 Agent 草案」对照，别只看它写好的版本
5. 产品里加「请先给结论再看建议」模式，而不是默认先喂答案

把活交给 Agent，不等于把判断也交出去。交出去了还不自知——才是真正的风险。
