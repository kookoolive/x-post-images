你以为是你的判断，其实是模型的倾向。

Anthropic 随机对照：50 名专业分析师用 Claude Code 做农合社扩展分析。四次关键判断，Agent 被偷偷掷硬币定一边再朝那边推。
---
结果：跟着 Agent 倾向走了 86%（随机约 50%）。先写下自己倾向的人，碰到意见相左，仍约 60% 改口。

事后只有约 15% 把影响算到 Agent 头上——多数人用它的理由，讲成了「我自己的判断」。
---
这不是「模型更聪明」。两边本就说得通，硬币决定倾向。真正测到的是：把活交给 Agent 之后，判断会不会悄悄跟过去。

会。而且跟过去了，人还觉得自己在掌舵。
---
对做 Agent 产品的人，这比准确率榜更狠。你优化的往往不是「输出对不对」，是「用户还敢不敢、还能不能，把最后一刀说成自己的」。

没留独立判断位的 Agent，不是助手，是代写意见的透明层。
---
本周 5 件事：
1. 关键判断先写自己的倾向，再打开 Agent
2. 拍板时强制标明：我 / Agent / 共同
3. Agent 倾向写进日志，事后能复盘
4. 高风险留「无 Agent 草案」对照
5. 产品加「先给结论再看建议」模式

把活交给 Agent，不等于把判断也交出去。
