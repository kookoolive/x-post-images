## post
真正吓人的不是「模型会写 exploit」。

是它能把几个互不相关的洞，串成一条能跑通的链——以前这件事，通常只落在极少数红队手里。

Anthropic Frontier Red Team 在 10-27 公开：过去几个月，他们用一款未发布的内部 Claude 研究模型，在 Chrome、Safari、Android、Windows、Linux 上写出 5 条可用攻击链。全是实验室 PoC，不是野外攻击；每条都先报厂商，补丁落地后再讲细节。

Chrome 一链最扎眼。初始提示之后，模型自己串出四步：V8 堆破坏 → 逃出 V8 内存沙箱并打掉 ASLR → 用 CacheStorage 竞态摸清浏览器进程布局 → FedCM 的 use-after-free 把代码送出沙箱。结果是：默认配置的 macOS Chrome，页面一加载，几秒内弹出计算器，无需再点。Google 侧已分配并修补 62 个 CVE，全部高危或严重，含 13 个沙箱逃逸、21 个可攻陷渲染进程的洞，Chrome 156 起生效。Google 发行说明里，部分条目明确写了 Anthropic 的 Xinyang Ge，并注明 assisted by Claude。

另四条同样不「可爱」：Safari 同源策略被拆开，恶意页可读你已登录站点的数据；Android 锁屏下经 USB 抽照片等数据；Windows 上对 HTTP/3 服务的远程拒绝服务（CVE-2026-33096）；Linux 多路径 TCP 监听器上的零点击远程 root（CVE-2026-98432）。

别把头条停在「AI 比人快」。单洞扫描早就有了；稀缺的是把互不相关的弱点收成一条可复现利用链。能力一旦外溢，真正值钱的不是又一个 PoC 视频，是协调披露能不能跟上——Anthropic 写的是 90 天修复窗口，再加 45 天才细讲。Agent 能写链，不等于该立刻秀链。没补丁的演示，是把刀柄递出去。

本周 5 件事：
1. 浏览器升到 Chrome 156+，内核与系统补丁别拖
2. 把「发现→复现→报告→公开」写进 Agent 安全工作流，禁止未报先晒
3. 红队 Agent 只许在隔离靶场跑，出口默认拒外联
4. 自有产品用 Agent 扫一版，优先看「能不能成链」，不要只盯单洞榜
5. 对外演示只放已补丁案例，PoC 细节走私密渠道

Agent 时代的安全债，不还在「会不会找洞」，而在「敢不敢先补再讲」。
