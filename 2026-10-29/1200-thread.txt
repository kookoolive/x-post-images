真正吓人的不是「模型会写 exploit」。

是它能把几个互不相关的洞，串成一条能跑通的链——以前这件事，通常只落在极少数红队手里。
---
Anthropic Frontier Red Team（10-27）：未发布的内部 Claude 研究模型，在 Chrome / Safari / Android / Windows / Linux 上写出 5 条可用攻击链。实验室 PoC，不是野外攻击；全部先报厂商、补丁落地后再公开。
---
Chrome 一链最扎眼：V8 堆破坏 → 逃出 V8 sandbox/ASLR → CacheStorage 竞态摸布局 → FedCM UAF 出沙箱。页面一加载，默认 macOS Chrome 几秒内弹出计算器。Google 侧已给 62 个 CVE，全是高危或严重，Chrome 156 修好；其中含 13 个沙箱逃逸。
---
另四条也不含糊：Safari 同源策略被拆开；Android 锁机 USB 抽数据；Windows QUIC 远程打挂（CVE-2026-33096）；Linux 多路径 TCP 零点击拿 root（CVE-2026-98432）。
---
头条别停在「AI 比人快」。能力往外扩时，真正值钱的是协调披露：90 天修 + 再 45 天才细讲。Agent 能写链，不等于该立刻秀链——没补丁的演示，是把刀柄递出去。
---
本周 5 件事：
1. 浏览器升到 Chrome 156+，内核与系统补丁别拖
2. 把「发现→复现→报告→公开」写进 Agent 安全工作流，禁止未报先晒
3. 红队 Agent 只许在隔离靶场跑，出口默认拒外联
4. 自有产品用 Agent 扫一版，优先链而不是单洞榜
5. 对外演示只放已补丁案例，PoC 细节走私密渠道

Agent 时代的安全债，不还在「会不会找洞」，而在「敢不敢先补再讲」。
