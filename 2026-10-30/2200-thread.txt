Agent 不是在告诉你它在忙——是在用账单买忙的样子。

Claude Code 大约每 30 秒，会把每个正在跑的后台 Agent 的整段 transcript 再喂回模型，只为写一个 3–5 个字的状态标签。五个字出去，整段对话进来，半分钟一轮。
---
有团队按周计量：状态标签占花销 16.4%，真正对话只占 15.7%。Anthropic 说均值大约 2%。两边可以同时成立——它随「并行 Agent × 上下文」放大。Agent 多、历史长，标签税就飙。
---
更阴的是：这些轮询往往不进 session log，只有 telemetry 导出才抓得到。你看不见，就砍不掉。按 session 对账会漏；必须按 source 拆——status poll、chat、tool 各记一本。
---
别把忙绿点当成免费 UX。看不见的轮询才是真成本。本周先把「告诉你我在忙」这项税从账单里抠出来。
---
本周 5 件事：
1. 账单按 source 拆：status poll / chat / tool，别只看 session 总额
2. 砍或降频后台 status 刷新——能关默认关
3. telemetry 与 session log 对齐对账，漏掉的轮询补进报表
---
4. 并行 Agent 数 × 上下文长度设硬上限，防标签税指数涨
5. 默认关掉无用 busy 标签轮询；真要看进度，用人触发，别让机器每 30 秒刷

看得见的绿点很便宜；看不见的 transcript 回灌很贵。
