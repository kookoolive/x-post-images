## post
Computer-use 卡住的，多半不是模型不会看图——是你在逼它猜像素。

Vercel Labs 开源了 agent-desktop：给任意 Coding Agent（Claude Code / Codex / OpenCode…）整机 computer-use。它不靠截图点按钮，而是读操作系统的 accessibility tree——和读屏软件同一张控件地图——再对稳定的 ref 发动作。macOS / Windows / Linux，Apache-2.0，Rust；可以后台跑，每个 Agent 各有自己的光标。

数字很直白。有人测过：看一眼 UI，截图路径大约 3811 token，AX 快照大约 273。官方自评密 UI 能少烧 78%–96% token；社区也有「任务从约 4 万降到约 2 千」的自报。像素路线在付「猜」的税；控件树路线在付「读」的税。后者便宜一个数量级，不是偶然。

别把它读成「以后不用管无障碍了」。反过来：没有 accessibility tree 的应用，对 Agent 等于隐形；你欠下的无障碍债，现在直接变成 Agent 债。快照里还有整屏内容——登录态、聊天、密钥都可能被读进上下文。能点不等于该点；能读不等于该进公开日志。

真正翻转的是接口层：Agent 的桌面 API，正在从「看图说话」变成「调用控件」。还在堆视觉模型去点坐标的人，会眼睁睁看着账单和失败率一起涨。

本周 5 件事：
1. 新接 desktop Agent 优先 AX / 控件树路径，像素只做兜底
2. 给核心桌面 App 补 accessibility 标签——这是给 Agent 的 API
3. 快照默认不出公共日志；脱敏后再进 telemetry
4. 桌面 Agent 跑在隔离环境（VM / 专用账户），别直接摸登录态
5. 账单按「截图 token vs AX token」拆，看哪条路径在烧钱

Computer-use 的下一站不是更大的眼睛，是更干净的控件树。
