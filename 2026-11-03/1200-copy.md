## post
高盛把 Claude Code 和 GitHub Copilot 从大部分交易员、银行家手里收回了，只留给工程师和 strats（Bloomberg 报道，10 月内部指引更新）。

别读成「AI 不行了」。收回的不是聊天，是「写代码并让它跑起来」这档权限。7 月，高盛 CIO 还在夸交易员 vibe coding 自己的小工具；据报道，有人拿它跟踪客户交易。原型一碰客户数据，就不是原型了。

区别不在会不会写代码，在出事有没有人认：工程师有评审、测试、上线流程；业务自己 vibe 出来的脚本，没人当 owner、没人审、没人说得清它在读哪些数据。

全行约 4.7 万人，多数不是工程师。高盛没关 AI，自家 GS AI Assistant 仍广泛开放。聊天可以人人有，执行要分级。

本周 5 件事：
1. AI 工具按聊天、写码、上线分档，权限别绑在一起
2. 业务自建脚本也要有 owner：谁维护、谁背锅
3. 碰客户/交易数据的代码，一律走评审和回滚
4. 别一刀切禁用，会逼人用个人账号偷跑
5. 原型阶段放开，上线前补一道人工门禁

vibe coding 的快是真的，账也是真的。
