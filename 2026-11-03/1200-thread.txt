1/6
高盛把 Claude Code 和 GitHub Copilot 从大部分交易员、银行家手里收回了，只留给工程师和 strats。别读成「AI 不行了」：收回的是「谁为上线的东西负责」。（Bloomberg 报道）

2/6
7 月，高盛 CIO 还在夸交易员 vibe coding 自己的小工具；10 月内部指引改了，权限只给更适合长期用的人。据报道，有人拿它跟踪客户交易。原型一碰客户数据，就不是原型了。

3/6
区别不在会不会写代码，在出事有没有人认。工程师有评审、测试、上线流程；业务自己 vibe 出来的脚本，没人当 owner、没人审、没人说得清它在读哪些数据。

4/6
全行约 4.7 万人，多数不是工程师。高盛没关 AI，自家 GS AI Assistant 仍广泛开放。收的只是「写代码并让它跑起来」这档权限：聊天可以人人有，执行要分级。

5/6
本周 5 事：① AI 工具按聊天、写码、上线分档 ② 业务自建脚本也要有 owner ③ 碰客户/交易数据的代码走评审和回滚 ④ 别一刀切禁用，会逼人用个人账号偷跑 ⑤ 原型放开，上线前补人工门禁

6/6
vibe coding 的快是真的，账也是真的。原型阶段可以放开，上线那一刻必须有人签字认账。权限分档不是倒退，是让这玩意儿能留在公司里继续用。
