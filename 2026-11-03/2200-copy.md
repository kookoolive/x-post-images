## post
Anthropic 和 OpenAI 这两天讲了同一件事：Git 被自家 Agent 写爆了。

Anthropic：主仓每天合入从 5 月约 2,500 次，涨到 9 月 30,000+。7 个人用 5 个月造了自家版本控制 Scion，把 monorepo 搬出 Git。OpenAI：主干合入量 Q3 比 2024 年 Q1 涨 1,378%，于是做了 Pando——不换 Git 客户端，只换服务端，push 中位延迟降近 80%，每天近 1PB。

两条路相反，结论一样：瓶颈从「写」挪到了「合」。Anthropic 自己也说 Scion 不是通用 Git 替代，多数仓库 Git 仍然够用。

我的判断：多数团队不需要自造 Scion。该做的是在 Agent 上量之前，先量清自己的合并队列、CI 拉取和评审吞吐。

本周 5 件事：
1. 量三个数：每天合入数、CI 拉取次数、平均排队时间
2. 给每个 Agent 设并发 PR 上限，别让 50 个抢一条分支
3. CI 用浅克隆/缓存/按需拉文件，别次次全量
4. 评审吞吐也是容量：合得快不等于有人看
5. 先优化服务端和流程，再谈换版本控制

写代码变便宜了，合代码、验代码才是新的排队窗口。
