## post
Revolut 把约 2,000 名工程师的默认编程模型，换成了自托管开源权重的智谱 GLM（AI Engineer NYC，AI ops 负责人 David Abitbol）。Claude Code 和 Codex 还在，但进了例外名单。

账单数字够硬：约 56 张 Nvidia B200，混合成本大约每百万 token 0.3 美元，AI 编程账单降到原先付给 Anthropic + OpenAI 的约十分之一。有人单月 Claude Code 账单曾到 1,000–10,000 美元——默认档一换，曲线就翻过来。

别读成「开源碾压旗舰」。难的活仍给 Claude Code / Codex。真正翻的是默认：日常写码走便宜、可控、自托管；旗舰模型变成按任务点名的例外。

高盛收权限，是谁能为上线负责；Revolut 换默认，是谁该为日常 token 付账。两件事对着看：一边管风险，一边管成本。

本周 5 件事：
1. 给 coding agent 分默认档与例外档，别全员绑旗舰
2. 量清楚每人每月 token 账单，别只看「有没有用」
3. 日常任务先压到自托管 / 开源权重，难题再升档
4. 设并发与上下文上限，防 1k–10k 美元账单重演
5. 验收标准先写清，便宜模型也要过同一道门

Agent 成熟之后，护城河不在「有没有最强模型」，在你敢不敢把默认档换成够用且算得清账的那一档。
