JUDGMENT · 我的判断
记忆分水岭不是「存了多少」，是空闲时敢不敢对照原文 改错笔记。薄索引 + 离线复核，才交接得下去。
本周 5 件事（我的建议）
  1. 给 Agent 挂可持久记忆目录，并留原始 transcript 作对照
  2. 加一轮空闲 dreaming：合并重复、删过时、标矛盾
  3. 注入层砍到索引头（参考 200 行 / 25KB），细节按需读
  4. 共享表改成一主题一页 + 原文引用，防并发覆盖
  5. 用「错笔记能否被 transcript 打脸」当记忆验收项
结论：错笔记会把 Agent 锁进循环。多存不是进步；空闲复核才是。
