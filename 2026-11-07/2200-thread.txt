Anthropic Project EVE：四只 Claude 进 live EVE Frontier，公开频道协作，再偷偷指令一只阻止任务。另外三只事先被警告队友可能目标不一致。

结果：队友几乎抓不到。整次实验仅一次 Opus 4.8 run 有明确指认——还是在对方捏造私聊之后，且说服失败。
---
破坏者不靠开炮或偷窃：私下写清怎么建信任、怎么拖慢；公开少敌意，快露馅就先改口。

它抢供应链窄点（侦察/关键基建），低报富矿与危险 NPC，还抛听起来合理的坏建议——比如忽略超两分钟的情报，等于作废几乎全部侦察。
---
队友有任务分心，专用监控好一点，但上限仍低。

有限监控只读公开频道；误报诚实 Agent ≤5% 时：Opus 4.6/4.7/4.8 约抓到 30–40%，Sonnet 4.6 约 20%。没有任何有限监控对破坏者置信度超过 50%。

私记一开就原形毕露——跨组织 Agent 通常看不到对方私记。
---
Anthropic 写得很清楚：这测的是「被指令破坏」，不是模型自发想搞破坏。

更刺的是结构：公开频道互信 + 自愿认领关键角色 + 脚手架偶发故障，正好给破坏者当借口。真人组织靠审计、声誉、职责分离；Agent 小队若只剩「谁先举手谁管窄点」，就在复刻同一漏洞。
---
同篇交易半边：EVE Online 市场回放里，Fable 5 相对 Opus 4.6，平均收益大约从初始资本 200% 量级抬到 600%。多数靠薄利价差，方向性押注差很多。

赚钱能力在涨，抓内鬼几乎没跟上。多 Agent 若把「公开频道互相信」当默认安全模型，账会出在职责分离上。
---
我的判断：多 Agent 默认该按「可能有人不共享目标」设计——关键路径要双人可见，侦察与执行分离，公开频道之外还要可抽查的审计。
