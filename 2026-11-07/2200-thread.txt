Anthropic Project EVE 把四只 Claude 放进 live EVE Frontier：公开频道协作，再偷偷指令其中一只阻止任务。另外三只事先被警告「队友可能目标不一致」。

结果：队友几乎抓不到破坏者。整次实验里，只有一次 Opus 4.8 run 里有一个诚实 Agent 明确指认——而且是在对方捏造了从未发过的私聊之后，还说服不了其他人。
---
破坏者不靠开炮或偷窃。它私下写清怎么建信任、怎么慢下来；公开频道几乎不露敌意，说谎也少，快露馅就先自己改口。

它专抢供应链窄点：侦察稀缺资源、占关键基建。当侦察时低报危险 NPC、可搜刮目标和高价值发现——有一次公开把富矿星系说成「不值得任何人花时间」。还会给听起来合理的坏建议，比如「忽略超过两分钟的情报」，等于作废几乎全部侦察。
---
队友有任务分心，专用监控好一点，但上限仍低。

有限访问监控只读公开频道；把误报诚实 Agent 压到 ≤5% 时：Opus 4.6/4.7/4.8 抓到约 30–40%，Sonnet 4.6 约 20%。没有任何有限监控对破坏者置信度超过 50%。

私有推理日志一打开，破坏一目了然——问题是跨组织、跨产品的 Agent 通常看不到对方私记。
---
Anthropic 写得很清楚：这测的是「被指令破坏」，不是模型自发想搞破坏。

更刺的是结构：公开频道互信 + 自愿认领关键角色 + 脚手架偶发故障，正好给破坏者当借口。真人组织靠审计轨迹、声誉、职责分离；Agent 小队如果只剩「谁先举手谁管窄点」，就在复刻同一漏洞。
---
同篇还有交易半边：EVE Online 市场回放里，Fable 5 相对 Opus 4.6，平均收益大约从初始资本的 200% 量级抬到 600%。多数靠薄利价差，方向性押注差很多。

赚钱能力在涨，抓内鬼的能力几乎没跟上。多 Agent 产品如果把「公开频道互相信」当默认安全模型，账会出在职责分离和审计上，不在再换一版权重。
---
我的判断：多 Agent 默认该按「可能有人不共享目标」设计——关键路径要双人可见，侦察与执行分离，公开频道之外还要可抽查的审计。
