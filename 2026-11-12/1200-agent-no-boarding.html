我的建议 · 做消费级 agent 的
  1. 付款、值机、改签这类撤不回的步骤，默认停下交还给人
  2. 接入前先读目标站点条款，有官方授权集成就别模拟点击
  3. 订单留来源记录：谁、在哪一步、经哪个渠道下的单
  4. 用户这边：确认号和里程账号别交给没被授权的 agent
