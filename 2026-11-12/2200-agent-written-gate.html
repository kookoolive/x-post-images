MY TAKE · 判断
敢上线，是因为对照物在真 AWS 上，合入闸对回归和安全复查不留例外。本地适合把「能不能调通」收短，权限和配额还得回真环境验。
我的建议
  1. agent 测 AWS 调用先走本地模拟器，测试环境不要放真云凭证
  2. 先看该服务的保真分数和 things-that-do-not-work，501 不是通过
  3. 权限、IAM 和限流必须在真 AWS 上验，模拟器放行不算数
  4. 让 agent 写实现，先准备能对照真实系统的测试，合入必须过闸
