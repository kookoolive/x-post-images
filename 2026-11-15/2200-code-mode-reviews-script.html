我的看法这是换调用方式，不是一张通用省额度的证明。运行时才算出来的路径，分类器看不见，真要拦的操作还是得写进规则或钩子。
我的建议 · 四件事
1
本机终端确认 ≥ 2.1.323，再用环境变量试一次，看顶部是否出现 Code Mode (experimental) is on
2
真要拦的路径和命令，写死 deny 规则或钩子，别指望 auto 模式把后算出来的路径审掉
3
需要 -p、SDK、VS Code 或云端会话的工作流先别改，这条能力现在覆盖不到
4
组织若不打算用，托管设置写成 0；项目级设置本来开不了它
