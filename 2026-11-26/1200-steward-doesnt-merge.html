仓库级 Claude Ship
管理员按仓库打开
Team 或 Enterprise 才能开。本机 /steward 和组织里的 PR Steward 不是同一个东西；后者已经在干活时，本机看守不会启动。
范围限制
只支持 GitHub。开了零数据保留、HIPAA 配置或客户自管密钥的组织用不了。按 token 计费；策略若调用 Claude 的审查，观察模式下也会产生 Code Review 费用。
我的看法
评审、修绿、放行拆成三个 agent，边界才清楚。修绿的不负责放行；本机 /ship 也不是云端自动合并。
我的建议
01
引用翻倍和回退下降时，写上这是 Claude Code 团队、审查只是其中一层
02
开 Approvals 先走观察模式，再写进 branch protection
03
把 PR Steward 和本机 /steward 分开配，不要默认它们会彼此接上
04
本机看守只开在你信任主干合入权限的仓库；公共库先自己提交再跑 /ship
把 Ship 听成会自动合并，会把边界看错。放行仍取决于策略、权限和分支规则。
