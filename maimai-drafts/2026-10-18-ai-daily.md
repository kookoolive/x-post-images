# title
AI早报：人要守三样

# body
10月18日 AI 早报，关键词：钥匙、验证、判断。

1）OpenCode 遭「大规模蒸馏攻击」，约 1.4% Console 用户受波及——都是绑了 OpenAI / Anthropic / Google Key 的人。攻击者要的是能刷模型的 Key，不是你的 prompt。存过 Key 的地方，建议先轮换一次。

2）Google 开源 Harness²：Agent 自己试几版提示词/工具/记忆/子 Agent，对比差异改出更好的 harness，不动模型权重。一轮修改就超过原版。

3）Claude 写了 Claude Code 约 90% 的代码，回滚降了四成。代码写得比人审得快时，瓶颈变成「证明它能用」——靠测试和多 Agent 互审。

4）有人按 Anthropic 用工数据外推：技术岗新招聘里初级占比从 27% 掉到 9%，照趋势 2027 年中归零。这是外推，不是公司计划。

5）中国拟对顶级模型权重出口设审批（参数 2 万亿 / 算力 10²⁶ / 全球前十踩一条就要批）；API 和 App 服务不受影响。

6）Odyssey 把模拟果蝇大脑放进世界模型，它在虚构世界里自己飞，X 上 434 万浏览。

我的判断：Agent 越能自己干活，人要守的就越是三样——钥匙、验证、判断。你最在意哪一件？
