## 短命题怎么自动做
目标：像 lijigang——一句够硬的问题或对立，少解释，不写成小作文。

选题优先级：
1. `inbox.md` 未用「短命题」
2. 当天早报/12:00 日更里抽出的产品判断（只取命题，不复述新闻）
3. `/workspace/leo-knowledge/` 近期决定、张力、默认档/例外档类判断
4. 仍空：Agent/产品一号位视角写一句对立或追问

写法：先落到可核对对象（谁、什么机制、哪档默认），再抛命题；态度挂事实；禁空态度、禁「不是A是B」金句模板、少用排版感符号。可无图。

## 实验连载怎么自动做（三 / 六）
目标：像 amelia/晓辉——第 N 天 / 第 N 版，过程可见，不编造。

选题优先级：
1. `rotation.md` 里进行中的系列（同名续写第 N+1）
2. `inbox.md` 未用「实验」
3. 本机真实进展：ops 日志、配置改动、验证数字、目录产物（必须当天或近两天有新痕迹）
4. 若无任何真实进展：当日降级为短命题，log 写「实验降级」——禁止编造实验天

写法：第 N 天做了什么 → 1–3 个可核对细节（路径、数字、前后对比）→ 下一步一句。可配截图/信息卡。系列名与天数写进 `rotation.md`。
